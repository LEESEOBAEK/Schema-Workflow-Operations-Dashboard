# Runtime Performance Baseline

측정일: 2026-07-26

대상 버전: Dashboard `0.1.0-candidate.1`

측정 환경: Windows 로컬, Nuxt production build, `localhost`

## 측정 범위

- API: `/api/dashboard`
- 카탈로그 프로젝트: 11개
- 화면에 투영된 Run: 112개
- 응답 크기: 162,337 bytes
- 반복: 최초 1회, 후속 10회
- 경고: 0건

`112`는 현재 대시보드 카탈로그 전체의 화면 투영 개수다. 포트폴리오에서 별도로 집계한 `68 canonical Run`과는 집계 범위가 다르므로 서로 대체하지 않는다.

## 판정

- 현재 개인 로컬 운영 규모에서는 기본 탐색 API 성능이 충분하다.
- 측정값은 이 PC와 현재 파일 규모의 기준선이며 다른 환경의 성능 보장이 아니다.
- 데이터베이스 전환이나 지연 로딩 최적화를 지금 즉시 진행할 근거는 없다.
- 파일 수와 응답 크기가 크게 증가하면 같은 방식으로 재측정한다.

## 재측정 조건

- 화면 투영 Run이 500개를 넘을 때
- 응답 크기가 1 MB를 넘을 때
- 후속 응답 P95가 500 ms를 넘을 때
- 운영 중 체감 지연이나 메모리 문제가 반복될 때
